TURN Relay Enabled

This room uses a TURN relay server (Metered) to help connect devices that can't reach each other directly.

When a direct connection isn't possible, your file data is routed through Metered's servers instead of going straight between your devices. The connection stays end-to-end encrypted — Metered relays the encrypted traffic but can't read its contents — though it can see connection metadata, such as your devices' IP addresses and how much data was transferred.

You're connected to a third-party signaling server (). It supplies this room's relay credentials, so the relay may not be Metered — it's whichever relay that server chooses, and it can see the same metadata.
